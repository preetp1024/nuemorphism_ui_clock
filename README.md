# Mini Date & Time Neumorphism UI

**Mini Date & Time Neumorphism UI** is an interactive, real-time clock built with neumorphism design principles. The clock displays the current time, day, and date with a visually appealing 3D effect. Users can switch between light and dark themes using a toggle button for an enhanced user experience.

## Features

- **Real-Time Time, Day & Date**: Displays the current time (24-hour format), day, and date.
- **Neumorphism Design**: Soft shadows, gradients, and rounded edges create a modern, 3D look.
- **Dark Mode Toggle**: Easily switch between light and dark themes.
- **Responsive Layout**: Optimized for both mobile and desktop devices.

## Technologies Used

- **HTML5** - For the basic structure and content of the page.
- **CSS3** - For styling, including neumorphic design and smooth theme transitions.
- **JavaScript** - For real-time clock updates and implementing the dark mode toggle.
